# C2: partition match (comparison)

Here are two designs of a related system, A and B, and the union (or intersection) of their test suites. Both pass all tests. Which has a branching partition closer to the input partition the tests force? Return -1 if B is closer, +1 if A is closer, 0 if they are tied or comparable. Justify in one sentence, naming the largest excess or missed branching distinction.
