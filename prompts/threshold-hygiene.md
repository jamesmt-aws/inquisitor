# Threshold hygiene

Here is a list of stated commitments about the system. For each, identify (a) the underlying preference, (b) whether the user has committed to a threshold, and if so what level. Flag any commitment whose preference is unclear or unmeasurable. Flag any threshold that is implicit (the user is acting as if a threshold exists but has not named it). Flag any commitment that mixes multiple preferences in a way that hides what is being traded against what.
