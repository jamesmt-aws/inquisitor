# C3: MDL compression (comparison)

Inputs: two design pairs, A = (design_A, code_A) and B = (design_B, code_B), and a test suite both code_A and code_B pass.

For each pair, take the two S3 measurements: path cost in both directions (token count for the same model to generate code from design and the reverse, under the held-fixed test suite), and artifact complexity in isolation (gzip size or line count, same measure for both).

Compare on the joint dimension: which pair lowers path cost while keeping artifacts simpler? Pareto-dominance is the rule.

- Return -1 if B Pareto-dominates A (B has lower or equal path cost in both directions and lower or equal artifact complexity, with at least one strict inequality).
- Return +1 if A Pareto-dominates B.
- Return 0 if neither dominates (the pairs trade off across the four cells).

Justify in one sentence, naming which dimension(s) drove the verdict.

Note: the same model and test suite must be used across A and B. Path-cost numbers are model-relative; ordering within one model is preserved even when absolute scale is meaningless.
