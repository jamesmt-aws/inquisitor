# C3: MDL compression (comparison)

Here are two designs of a related system, A and B, each presented at two resolutions (lower-resolution architecture or design document, higher-resolution code). Which lower-resolution description does more compression work for its higher-resolution one? Use gzip ratio (size of joint compressed / size of code compressed) as a first approximation. Return -1 if B compresses more, +1 if A compresses more, 0 if tied or if either design lacks a separable design layer. Justify in one sentence.
