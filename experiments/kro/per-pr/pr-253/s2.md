# S2: partition match (PR #253)

## Input partition

- Production reads field / does not.
- Caller of an interface uses the abstraction / there is no second caller.
- Test harness initializes from one source / from another.
- Condition lookup by type (Ready, Failed, Synced, etc.).
- AST walked by one consumer / by another / shared.
- forceApply YAML shape (typed only / typed + string).
- Prune outcome (succeeded / failed / patch-skipped).
- Public API surface readable from external packages.

## Branching partition (pre)

- Production-vs-non-production cells appear in CompiledGraph (5 dead fields), Topology (allocated paths), state (write-only fields), parameters (resyncCorrection), constants (FinalizeSkippedStates etc), exports (11 symbols).
- Interface-dispatch cell exists for GVKScopeResolver despite one implementation.
- Test-harness cells: testenv.Environment vs main_test.go's duplicate.
- Condition-extractor cells: graphReadyType, graphReadyMessage, ... per condition.
- AST-walker cells: two parallel walkers in fieldpath.go plus AllExpressions's own.
- forceApply cells: typed Force vs string "true".
- Prune outcome cells: pruneReleased vs other outcomes.

## Branching partition (post)

- Production-vs-non-production cells: only production cells remain.
- Interface-dispatch cell collapsed to direct call.
- Test-harness cells: only testenv.Environment.
- Condition-extractor: one parameterized extractor.
- AST-walker: one `walkAST` + `astVisitor`.
- forceApply: one cell (typed Force).
- Prune outcome: uniform; patches identified at type-check site.

## Cells in pre's branching partition not in post's

- **Production-vs-dead cells** (across CompiledGraph, Topology, state, parameters, constants, exports). Classification: **(b) deleted**. Input cases for the dead cells did not exist; deleting loses no preference value.
- **Single-impl interface cell.** Classification: **(a) relocated to dispatch**. Direct call replaces interface; the input case (alternative implementations) was not in the input partition.
- **Duplicated test harness cell.** Classification: **(a) relocated to module structure**.
- **Per-condition extractor cells.** Classification: **(a) relocated to a richer cost function** (parameterized helper). The input case (different conditions) is preserved; the branching shape changes.
- **Parallel AST walker cells.** Classification: **(a) relocated to module structure** (shared helper).
- **forceApply string-form cell.** Classification: **(b) deleted**. Input case (undocumented YAML shape) not in the preference-rewarded partition.
- **pruneReleased cell.** Classification: **(a) relocated to types** (patch identified by type check).

## Cells in post's branching partition not in pre's

- None genuinely new at the cell level. The post partition is strictly a coarsening (collapse of over-fine cells) plus three structure-level additions handled at S1.

## Verdict

**S2 improved.** Pre's branching partition was finer-than-required across many axes (every dead surface, every duplication, every single-impl interface). Post collapses the over-fine cells without losing any preference-required input case. The partition shape moves toward the input partition the preferences actually reward.

Citation: thirteen pre cells collapse via (a) relocation or (b) deletion; zero preference-required cells lost.
