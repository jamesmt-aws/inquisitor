# S3: MDL compression (PR #245)

Code shrank ~100K bytes (-23%). Design shrank because the architecture section dropped optimization-layer claims; the holding-pen design absorbs the rest.

## Predictability of code given design

**Pre.** Score: 1 / 5. Pre-state design has to describe the core algorithm AND the optimization layer's invariants (when does the hash skip; what does Path 1/2/3 distinguish; how do worker dispatch ordering interact with self-refresh; how does forEach per-item skip compose with the per-item gate). A regenerator following this design produces an implementation with many degrees of freedom the design does not pin down. Optimization-layer correctness depends on subtle invariants the design states informally.

**Post.** Score: 5 / 5. Post-state design names a sequential loop. A regenerator produces almost exactly the implementation. There is one place where state crosses reconciles (the apply-hash on SSA), and that is named explicitly.

## MDL comparison

Largest-leverage MDL move in the corpus. The pre-state design and code together had to specify how the optimization layer's correctness invariants compose with the core algorithm. Post-state's design specifies just the core; the holding pen absorbs everything else as deferred work.

Net structural absorption: -2443 lines of code (one of the biggest in the corpus). Files dominated by optimization machinery (walk.go -51%, controller.go -40%, hash.go -62%) shrink toward what the core algorithm requires.

## Verdict

**S3 improved.** Code shrank 23%. Design shrank in proportion. Predictability rose from 1 to 5. New structure (the holding-pen design at #244, plus the simple sequential loop) earns its keep against what it absorbs (3-layer hash, trigger routing, resync timers, worker dispatch, forEach skip, watch cache).

Citation: -23% code bytes, design shrinks proportionally, conditional cost drops from very high to near-zero. The pair of (#244 holding pen, #245 implementation strip) is the canonical instance of the MDL move described in `simplicity-doc.md`.
