- **Watch incremental cache merging** (P7). Classification: **(a) deleted**. Input case: integrating events without full re-list. Not preference-required at the controller layer.
- **Evaluation cache snapshot**. Classification: **(a) deleted**. Same reasoning.
- **Heavy implementation surface** (P8 pre). Classification: **(a) deleted via the above**. Pre's "files are dominated by optimization machinery" property is replaced by post's "files shrink substantially."
