# S2: partition match (PR #261)

## Input partition

- Compile-time concept vs reconcile-time concept.
- Pure DAG operation (BuildDAG, DetectCyclesEarly) vs walk-state value (NodeState, PlanState, PlanSummary).
- New contributor reading the import graph to learn the architecture.

## Branching partition (pre)

- `dag/` package contains both compile-time and reconcile-time types.
- Three reconcile-time files import `dag/` solely for state types; their dependence on `dag/` does not reflect a true compile-time dependency.
- The two phases (compile, reconcile) are not branched on at the package boundary.

## Branching partition (post)

- `dag/` package contains compile-time concepts only.
- Reconcile-time files contain reconcile-time concepts; no `dag/` imports for state.
- Phases are branched on at the package boundary; the import graph reflects the split.

## Cells in pre's branching partition not in post's

- **Mixed-package cell** (`dag/` containing reconcile-time types). Classification: **(a) relocated to module structure**. The distinction (compile-time vs reconcile-time) is now encoded at the package level; pre's `dag/` had a finer-than-required cell that mixed the two.
- **Spurious cross-package imports cell** (reconcile-time files importing `dag/` for state types). Classification: **(a) relocated**. The dependency edge moves with the file; reconcile-time files no longer pretend to depend on `dag/`.

## Cells in post's branching partition not in pre's

- **Phase-aware import-graph cell.** Classification: **(a) preferences require this distinction**. Public API stability and observable architecture both reward the import graph encoding the design's claim. Pre's branching partition was coarser than the input partition required: "what phase is this concept" was an input case the design did not distinguish at the package boundary.

## Verdict

**S2 improved.** Pre's branching partition was finer-than-required along one axis (package contents) and coarser-than-required along another (phase distinction at the import graph). Post collapses the over-fine cell (single-phase package) and adds the missing one (phase-encoded imports).

Citation: pre's mixed-package cell collapses via module-structure relocation; post's phase-aware imports satisfy an input case pre did not distinguish.
