# S3: MDL compression (PR #261)

Code grew slightly (+4287 bytes; mostly added comments documenting the new layout, plus duplicated import lines in transition). Design length is approximately equal at the level of structural commitments.

## Predictability of code given design

**Pre.** Score: 3 / 5. The design says "compile-time DAG construction in `dag/`" but the code places reconcile-time output types there too. A regenerating implementer working from pre-design would either follow the design's claim (and produce a different package layout from what's there) or follow the code (and reproduce the misplacement). The design and the code disagree on the package boundary's meaning.

**Post.** Score: 5 / 5. The design says "`dag/` = compile-time, `controller/` = reconcile-time" and the code matches exactly. A regenerator producing this layout from the design would arrive at the same package contents.

## MDL comparison

The interesting MDL move here is not in raw byte count. It's in the cost of the description that says "where does this type live" for a contributor adding a new reconcile-time concept. Pre-state requires the description "NodeState lives in `dag/` for historical reasons even though it is reconcile-time output" — that conditional is itself description length the design has to carry. Post-state requires only "reconcile-time concepts live in `controller/`" — the pattern is uniform.

The lower-resolution description (architectural claim) compresses the higher-resolution one (file locations) more efficiently in post: one rule covers the case that pre needed an exception for.

## Verdict

**S3 improved.** Code grew slightly but predictability of code given design rose from 3 to 5. The architectural rule in post is universal; in pre it had a documented exception. New structure (single-phase `dag/`) earns its keep against the cost of describing the exception that pre carried.

Citation: predictability 3 → 5 because the package boundary is a faithful projection of the design's compile-vs-reconcile claim; rule-level description shrinks even though file-level bytes do not.
