# S2: partition match (PR #249)

## Input partition

- Method requires API server access / does not.
- Method needs per-reconcile context (graph, watcher, name, namespace) / does not.
- Lifecycle stage: per-reconcile prune vs teardown.
- Optimization layer: in or deferred.
- Condition evaluation: readyWhen / propagateWhen / includeWhen.
- Resource identity: scope, GVK→GVR mapping, label keys.
- Public API: consumed externally / used internally only.

## Branching partition (pre)

- Receiver cell: GraphReconciler with both orchestration and execution methods.
- Parameter cells: (graph, watcher, name, namespace) repeated everywhere; each callee re-derives name/namespace.
- Lifecycle cells: teardown distinct from prune.
- Optimization cells: cache hit/miss in graphcache, apply-hash match/mismatch in hash, metric-on/off in metrics.
- CEL builder cells: ready vs updated as separate builders.
- File cells: scope.go vs resourcekey.go; deletion.go vs prune.go; gvkToGVR in controller.
- forEach state cells: forEachState vs forEachCarryForward.
- Parameter cell: nodeType vs node.Type().
- Public API cells: 11 exported symbols.
- Helper cells: 3 namespace defaultings; per-call-site SSA + status.
- Condition evaluator cells: three separate implementations.

## Branching partition (post)

- Receiver cells: GraphReconciler (orchestration) vs clusterAccess (execution); legible split.
- Parameter cell: *reconcileScope (one type).
- Lifecycle cell: pruneResources (single path; teardown is "all nodes are candidates").
- Optimization cells: collapsed (deferred to holding pen).
- CEL builder cell: one parameterized factory.
- File cells: collapsed via merges.
- forEach state cell: unified type.
- Parameter cells: only what node.Type() can't derive.
- Public API cells: only externally-consumed symbols.
- Helper cells: defaultNamespace; ssaWrite.
- Condition evaluator cell: evalConditions with parameter.

## Cells in pre's branching partition not in post's

- **Receiver mixed-concern cell.** Classification: **(a) relocated to types** (two receivers).
- **Four-parameter cells.** Classification: **(a) relocated to types** (`reconcileScope`).
- **Teardown-vs-prune cells.** Classification: **(a) relocated to module structure** (one path).
- **Cache, apply-hash, metric cells.** Classification: **(b) deleted**. Input cases not in preference-rewarded partition.
- **Repeated CEL registration cells.** Classification: **(a) relocated**. Single helper.
- **Two CEL function builder cells.** Classification: **(a) relocated** (parameterized factory).
- **Standalone-file cells.** Classification: **(a) relocated to module structure** (merges).
- **Two forEach state cells.** Classification: **(a) relocated to types**.
- **Redundant nodeType cells.** Classification: **(b) deleted**. Input distinction was already available from node.Type().
- **Three namespace-defaulting cells.** Classification: **(a) relocated** (single helper).
- **Per-call-site SSA cells.** Classification: **(a) relocated** (`ssaWrite`).
- **Three condition-evaluator cells.** Classification: **(a) relocated** (`evalConditions`).
- **Unexported-now-public cells.** Classification: **(a) relocated to module structure**.

## Cells in post's branching partition not in pre's

- **Receiver split cell.** Classification: **(a) preferences require this distinction**. Input case "does this method need API access" is now branched on at the type level.
- **Per-reconcile-context lifetime cell.** Classification: **(a) preferences require**. `*reconcileScope` makes the lifetime explicit.

## Verdict

**S2 improved.** Twelve over-fine cells collapsed via (a) relocation or (b) deletion. Two preference-required cells added (receiver split, per-reconcile lifetime). The change is the cleanest partition-match move in the corpus alongside #245.

Citation: twelve pre cells collapse; two post cells add. No preference-required input case lost.
