# S3: MDL compression (PR #172)

## Byte counts

| | design (md) | code (touched files) |
|---|---:|---:|
| pre | ~1700 | 836788 |

Net: design shrank ~200 bytes (no longer needs to document the divergence); code shrank ~352 bytes (a few longer-name strings replaced with shorter ones, near zero net).

## Predictability of code given design

**Pre.** Score: 3 / 5. The design correctly states that NodeType has values template and patch, but a regenerating implementer reading pre-state code would also encounter "Own" and "Contribute" in comments and log fields and would not know which vocabulary to use. The design carries an honest property describing the divergence, which forces the implementer to make a choice that the design does not pin down.

**Post.** Score: 4 / 5. Vocabulary is uniform across types, comments, log fields, and tests. A regenerator hits one consistent name per concept and produces one consistent output. The improvement is small in MDL terms because the conditional cost change is mostly reduction in implementer ambiguity, not reduction in description length.

## MDL comparison

`|design| + cost(code | design)` is essentially flat across the change. Bytes are nearly equal on both sides; predictability rose marginally. No new structure introduced that earns its keep against a deleted runtime guard or comment obligation; what was deleted was duplicate vocabulary, not duplicate structure.

## Verdict

**S3 unchanged.** Bytes are flat; predictability rose by a small qualitative margin. S3 measures whether a lower-resolution description compresses a higher-resolution one more efficiently after the change; a renaming does not change compression efficiency at the file-size level. Predictability rises because vocabulary is consistent, but the rise is below what would justify `improved` against an MDL framing that uses bytes as the proxy.

This is the same orthogonal signal as S1 and S2: the change improves something real (consistent vocabulary aiding human and machine readers) but the dimension is not what S3 measures.

Citation: bytes flat (-352 / -200); predictability 3 → 4 with margin attributable to vocabulary rather than structure.
