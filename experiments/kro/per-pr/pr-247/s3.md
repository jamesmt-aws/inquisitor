Code shrank ~60K bytes (-10%). Design shrank because the architecture section dropped optimization-layer claims; the lower-resolution description is shorter.

## Predictability of code given design

**Pre.** Score: 2 / 5. Pre-state design has to describe both the core algorithm and the optimization layer (cache, sharing, precompile, carry-forward). A regenerator following this design would produce two layers of machinery with implicit invariants connecting them. The conditional cost is high because the optimization layer's implementation has many degrees of freedom the design does not pin down.

**Post.** Score: 4 / 5. Post-state design names the core algorithm and points at `007-optimizations.md` for the layer that's deferred. A regenerator produces a sequential walk plus a flat instance-state map; the named apply steps and struct-level carry-forward give the implementation a small variance.

## MDL comparison

The interesting MDL move: the holding-pen design (`007-optimizations.md`) absorbs claims that the controller used to make at the implementation level. By relocating these claims, post-state's `(controller design + 007 design + code)` is shorter than pre's `(controller design + code with optimization layer)`. The split into core + holding pen earns its keep because the controller no longer pays for documenting optimization invariants in the same artifact as the core algorithm.

Net structural absorption: -1522 lines of code, -10% design surface area, +1 separated holding-pen design (already in tree as #244).

## Verdict

**S3 improved.** Code shrank substantially; design shrank in proportion; predictability rose from 2 to 4. New structure (the named apply procedures, the struct-level carry-forward, the holding-pen design at #244) earns its keep against what it absorbs (cache code, content-addressed sharing code, dead interfaces, dead metrics, monolithic apply, duplicated preflight).

Citation: -10% code bytes, design shrinks proportionally, conditional cost drops; the holding-pen split is the high-leverage move.
